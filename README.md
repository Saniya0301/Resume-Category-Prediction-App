# 📂 Resume Category Prediction App  

A **Streamlit-based NLP application** that predicts the **job category** of a given resume.  
Users can upload resumes in **PDF, DOCX, or TXT** formats, and the app classifies them into predefined categories using a trained **Machine Learning model**.  

---

## ✨ Features  
- 📄 **Upload resumes** in PDF, DOCX, or TXT format  
- 🤖 **Text preprocessing** (cleaning, tokenization, TF-IDF vectorization)  
- 🎯 **Job category prediction** using a trained ML model  
- ⚡ **Interactive UI** powered by Streamlit  
- 🔍 Supports real-time predictions with minimal latency  

---

## 🛠️ Tech Stack  
- **Python** 🐍  
- **Streamlit** (Web App Framework)  
- **Scikit-learn** (ML model training)  
- **NLTK / SpaCy** (Text preprocessing)  
- **Pickle** (Model serialization)
